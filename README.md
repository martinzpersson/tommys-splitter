# 📱 PDF Spirit Android App

**Crop postal labels on your GrapheneOS phone!**

## 🎯 What This Is
Native Android app that crops PostNord PDF labels for perfect printing. Works completely offline - perfect for privacy-focused GrapheneOS users.

## 🚀 Features
- **📄 Auto-scan Downloads** - Finds PDF files automatically
- **👆 One-tap processing** - Simple touch interface  
- **📊 Progress indicators** - Visual feedback during processing
- **✅ Success notifications** - Shows where files are saved
- **📱 Native Android UI** - Feels like a real Android app
- **🔒 Completely offline** - No internet required, no tracking

## 📱 How It Works
1. **Download** PDF label to your phone
2. **Open PDF Spirit** app
3. **Tap "Scan for PDFs"** - finds files automatically
4. **Tap "Process"** on your PDF
5. **Success!** - Edited PDF saved to Documents/PDFSpirit
6. **Print** directly from your phone

## 🔒 Privacy Perfect
- ✅ **No internet permissions** - Works completely offline
- ✅ **No tracking** - Zero data collection
- ✅ **Local processing** - Files never leave your device
- ✅ **Open source** - You can audit all code
- ✅ **GrapheneOS compatible** - Respects your privacy choices

## 🏗️ Building the APK
This repository is configured with **GitHub Actions** to automatically build the Android APK.

### Automatic Build
1. **Push code** to this repository
2. **GitHub Actions** automatically builds APK
3. **Download APK** from Actions artifacts
4. **Install** on your GrapheneOS phone

### Manual Build (Advanced)
See `BUILD_INSTRUCTIONS.md` for local building with WSL/Linux.

## 📥 Installation
1. **Download APK** from GitHub Actions artifacts
2. **Copy to phone** via USB, cloud, or direct download
3. **Enable "Install unknown apps"** in Android settings
4. **Tap APK file** to install
5. **Done!** Look for "PDF Spirit" in your app drawer

## 🔧 Technical Details
- **Built with:** Python + Kivy + PyPDF2
- **Target:** Android API 21+ (Android 5.0+)
- **Size:** ~15-20 MB
- **Permissions:** Storage access only
- **Architecture:** ARM64, ARMv7
