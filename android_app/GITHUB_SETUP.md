# 🚀 PDF Spirit - GitHub Actions Build Setup

## 📋 Quick GitHub Setup (5 minutes)

### Step 1: Create Repository
1. Go to **https://github.com/new**
2. Repository name: `pdf-spirit-android`
3. Make it **Public** (for free Actions)
4. Click **"Create repository"**

### Step 2: Upload Files
**Option A - Web Upload:**
1. Click **"uploading an existing file"**
2. Drag and drop all files from `android_app` folder
3. Commit message: `"PDF Spirit Android App"`
4. Click **"Commit changes"**

**Option B - Git Commands:**
```bash
git init
git add .
git commit -m "PDF Spirit Android App"
git remote add origin https://github.com/YOUR_USERNAME/pdf-spirit-android.git
git branch -M main
git push -u origin main
```

### Step 3: Watch the Magic
1. Go to **Actions tab** in your repo
2. See **"Build PDF Spirit APK"** running
3. Wait ~10 minutes for completion
4. **Green checkmark** = success!

### Step 4: Download APK
1. Click the **completed build**
2. Scroll down to **"Artifacts"**
3. Download **"pdfspirit-apk"**
4. Extract ZIP → get your APK!

## 📱 Install on GrapheneOS
1. Copy APK to your phone
2. Enable "Install unknown apps"
3. Tap APK to install
4. **PDF Spirit is ready!**
